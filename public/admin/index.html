❓ Hilfe - Webinar Platform Admin

📚 Übersicht

Willkommen im Admin-Panel der Webinar Platform! Diese Anleitung erklärt Ihnen Schritt für Schritt, wie Sie Webinare erstellen, verwalten und PPTX/PDF-Präsentationen importieren können.

🎯 Webinar erstellen

Schritt 1: Webinar-Bereich öffnen

Klicken Sie in der Navigationsleiste oben auf Webinare.

Schritt 2: Neues Webinar erstellen

Klicken Sie auf den Button Neues Webinar erstellen. Ein Formular öffnet sich.

Schritt 3: Webinar-Titel eingeben

Geben Sie einen aussagekräftigen Titel für Ihr Webinar ein (z.B. "Einführung in die Webentwicklung").

Schritt 4: Präsentationsdatei auswählen (optional)

Falls Sie bereits eine PPTX- oder PDF-Datei hochgeladen haben, können Sie diese hier auswählen. Die Folien werden automatisch aus der Präsentation extrahiert.

💡 Hinweis: Sie können Webinare auch ohne Präsentationsdatei erstellen und die Folien manuell hinzufügen.
Schritt 5: Folien hinzufügen

Klicken Sie auf Folie hinzufügen und füllen Sie folgende Felder aus:

  • Titel: Der Titel der Folie (wird oben angezeigt)
  • Inhalt: Der Hauptinhalt der Folie (unterstützt HTML-Formatierung)
  • Sprechernotiz: Text für die automatische Sprachausgabe (wird nicht auf der Folie angezeigt)
💡 Tipp: Verwenden Sie den Rich-Text-Editor für formatierte Inhalte mit Überschriften, Listen, Bildern und Tabellen.
Schritt 6: Lernkontrolle-Fragen hinzufügen

Fügen Sie Quiz-Fragen hinzu, um das Wissen der Teilnehmer zu testen:

  1. Klicken Sie auf Frage hinzufügen
  2. Geben Sie die Frage ein
  3. Geben Sie 4 Antwortmöglichkeiten ein
  4. Markieren Sie die richtige Antwort mit dem Radio-Button
Schritt 7: Speichern

Klicken Sie auf Speichern, um das Webinar zu erstellen. Es wird automatisch in der Liste angezeigt.

📤 PPTX/PDF importieren

Schritt 1: Import-Dialog öffnen

Klicken Sie in der Navigationsleiste auf den grünen Button 📤 Import (PPTX/PDF).

Schritt 2: Dateien auswählen

Klicken Sie auf Dateien auswählen und wählen Sie eine oder mehrere PPTX- oder PDF-Dateien von Ihrem Computer aus.

✅ Unterstützte Formate:
  • PowerPoint-Präsentationen (.pptx, .ppt)
  • PDF-Dokumente (.pdf)
Schritt 3: Importieren

Klicken Sie auf Importieren. Die Dateien werden hochgeladen und verarbeitet.

⚠️ Wichtig: Je nach Dateigröße kann der Upload einige Sekunden dauern. Bitte warten Sie, bis die Erfolgsmeldung erscheint.
Schritt 4: Verwendung der importierten Präsentation

Die hochgeladene Präsentation erscheint in der Liste. Sie können sie jetzt bei der Webinar-Erstellung auswählen:

  • PDF: Seiten werden als Bilder extrahiert und automatisch den Folien zugeordnet
  • PPTX: Bilder und Grafiken werden extrahiert und den Folien zugeordnet
Präsentationen verwalten

Im Import-Dialog sehen Sie alle hochgeladenen Präsentationen. Sie können diese auch löschen, wenn sie nicht mehr benötigt werden.

✏️ Webinare bearbeiten und verwalten

Webinar bearbeiten

Um ein bestehendes Webinar zu bearbeiten:

  1. Gehen Sie zum Bereich Webinare
  2. Klicken Sie bei dem gewünschten Webinar auf Bearbeiten
  3. Nehmen Sie Ihre Änderungen vor
  4. Klicken Sie auf Speichern

Webinar löschen

Um ein Webinar zu löschen:

  1. Gehen Sie zum Bereich Webinare
  2. Klicken Sie bei dem gewünschten Webinar auf Löschen
  3. Bestätigen Sie die Löschung
⚠️ Achtung: Gelöschte Webinare können nicht wiederhergestellt werden!

Webinar anzeigen

Um ein Webinar in der Teilnehmer-Ansicht zu öffnen:

  1. Klicken Sie bei dem gewünschten Webinar auf Anzeigen
  2. Das Webinar öffnet sich in einem neuen Tab

📊 Ergebnisse verwalten

Im Bereich Ergebnisse finden Sie alle eingereichten Quiz-Ergebnisse:

  • Name: Name des Teilnehmers
  • E-Mail: E-Mail-Adresse des Teilnehmers
  • Webinar: Name des absolvierten Webinars
  • Punktzahl: Erreichte Punktzahl
  • Bestanden: Status (Bestanden/Nicht bestanden)
  • Datum: Zeitpunkt der Teilnahme

CSV-Export

Klicken Sie auf Als CSV exportieren, um alle Ergebnisse in einer Excel-kompatiblen Datei zu speichern.

⚙️ Einstellungen

Header-Konfiguration

Passen Sie das Erscheinungsbild der Webinar-Plattform an:

  • Header-Titel: Ändern Sie den Titel, der auf allen Seiten angezeigt wird
  • Logo: Laden Sie Ihr eigenes Logo hoch (PNG, JPG, SVG)

E-Mail-Konfiguration (SMTP)

Richten Sie den E-Mail-Versand ein, um automatisch Ergebnisse zu versenden:

  1. Gehen Sie zum Bereich E-Mail (SMTP)
  2. Geben Sie Ihre SMTP-Server-Details ein
  3. Testen Sie die Konfiguration mit einer Test-E-Mail
  4. Speichern Sie die Einstellungen
💡 Tipp: Für Gmail verwenden Sie smtp.gmail.com auf Port 587 und ein App-spezifisches Passwort.

🗣️ Sprachausgabe

Die Webinar-Plattform bietet automatische Sprachausgabe für Sprechernotizen:

  • Geben Sie bei jeder Folie eine Sprechernotiz ein
  • Diese wird automatisch vorgelesen, wenn die Folie angezeigt wird
  • Teilnehmer können die Stimme und Geschwindigkeit anpassen
  • Verwenden Sie vollständige Sätze mit korrekter Interpunktion für beste Ergebnisse

💡 Tipps & Best Practices

  • Kurze Folien: Halten Sie Folien übersichtlich mit 3-5 Hauptpunkten
  • Klare Struktur: Verwenden Sie Überschriften und Aufzählungen
  • Bilder verwenden: Nutzen Sie den Rich-Text-Editor, um Bilder einzufügen
  • Quiz-Fragen: Fügen Sie 3-5 Fragen pro Webinar hinzu
  • Sprechernotizen: Schreiben Sie 2-4 Sätze pro Folie für die Sprachausgabe
  • Regelmäßig speichern: Speichern Sie Ihre Änderungen regelmäßig
  • Vorschau nutzen: Testen Sie Ihr Webinar mit "Anzeigen" vor der Veröffentlichung

❓ Häufige Fragen

Kann ich vorhandene PowerPoint-Präsentationen verwenden?

Ja! Laden Sie Ihre PPTX- oder PDF-Datei über 📤 Import (PPTX/PDF) hoch. Die Folien werden automatisch extrahiert und können als Basis für Ihr Webinar verwendet werden.

Wie viele Folien kann ein Webinar haben?

Es gibt keine technische Begrenzung. Für beste Lernergebnisse empfehlen wir 10-20 Folien pro Webinar.

Kann ich HTML in den Folien verwenden?

Ja! Der Rich-Text-Editor unterstützt HTML-Formatierung. Sie können auch direkt HTML-Code einfügen.

Werden die Ergebnisse automatisch per E-Mail versendet?

Ja, wenn Sie SMTP konfiguriert haben, werden die Ergebnisse automatisch an die konfigurierte Empfänger-Adresse gesendet.

Kann ich ein Webinar nachträglich bearbeiten?

Ja, jederzeit! Klicken Sie einfach auf Bearbeiten beim entsprechenden Webinar.
