## Webinar ansehen

### Zugriff auf Webinare

1. Öffnen Sie die Webinar-Plattform in Ihrem Browser
2. Wählen Sie ein Webinar aus der Liste
3. Das Webinar startet automatisch

### Navigation

**Tastatur:**
- ➡️ Pfeiltaste rechts: Nächste Folie
- ⬅️ Pfeiltaste links: Vorherige Folie
- ⬆️ Pfeiltaste oben: Vorheriger Abschnitt
- ⬇️ Pfeiltaste unten: Nächster Abschnitt
- **Leertaste**: Nächste Folie
- **ESC**: Übersicht (alle Folien)
- **F**: Vollbildmodus

**Maus:**
- Klicken Sie auf die Navigationspfeile unten rechts
- Wischen Sie auf Touch-Geräten nach links/rechts

### Sprachausgabe

Die Webinar-Plattform bietet automatische deutsche Sprachausgabe für jede Folie.

**Steuerung:**
- 🔊 **Stummschalten**: Klicken Sie auf das Lautsprecher-Symbol
- 🎚️ **Geschwindigkeit**: Nutzen Sie den Schieberegler (0.5x - 1.5x)
- ⏸️ **Pause**: Die Sprachausgabe pausiert automatisch bei Navigation

**Empfohlene Browser für beste Sprachqualität:**
- Google Chrome
- Microsoft Edge

Die Sprachausgabe verwendet **Piper TTS** für hochwertige, natürlich klingende deutsche Stimmen.

### Folientypen

**Standard-Folie:**
- Titel, Text, Bilder, Listen
- Normale Präsentationsinhalte

**Hero-Folie:**
- Großer, auffälliger Titel
- Gradient-Hintergrund
- Für wichtige Ankündigungen oder Kapitel-Trenner

**2-Spalten-Layout:**
- Text und Bild nebeneinander
- Vergleiche, Pro/Contra-Listen

**3-Spalten-Layout:**
- Drei gleichwertige Bereiche
- Feature-Vergleiche, Schritt-für-Schritt-Anleitungen

## Quiz absolvieren

### Quiz starten

1. Absolvieren Sie das gesamte Webinar
2. Am Ende erscheint automatisch das Quiz
3. Alternativ: Navigieren Sie zur letzten Folie

### Fragen beantworten

1. Lesen Sie jede Frage aufmerksam
2. Wählen Sie eine der vier Antwortmöglichkeiten
3. Klicken Sie auf "Weiter" für die nächste Frage

### Ergebnis einreichen

1. Geben Sie Ihren Namen ein
2. Geben Sie Ihre E-Mail-Adresse ein
3. Klicken Sie auf "Ergebnis einreichen"
4. Sie erhalten eine Bestätigung mit Ihrer Punktzahl
5. Die Ergebnisse werden per E-Mail zugestellt

### Bewertung

- Jede Frage hat eine richtige Antwort
- Die Punktzahl wird automatisch berechnet
- Ergebnisse werden im Admin-Panel gespeichert

## TipTap Editor - Inhalte erstellen

Der TipTap-Editor ist ein moderner WYSIWYG-Editor für die Erstellung von Webinar-Inhalten.

### Textformatierung

**Basis-Formatierung:**
- **Fett** (Strg/Cmd + B)
- *Kursiv* (Strg/Cmd + I)
- <u>Unterstrichen</u> (Strg/Cmd + U)
- ~~Durchgestrichen~~

**Überschriften:**
- H2: Haupt-Titel der Folie
- H3: Untertitel
- H4: Kleinere Abschnitte

Verwenden Sie eine konsistente Hierarchie für bessere Lesbarkeit.

### Listen

**Aufzählungsliste:**
1. Klicken Sie auf das Aufzählungslisten-Symbol (•)
2. Geben Sie Ihre Punkte ein
3. Drücken Sie Enter für einen neuen Punkt
4. Drücken Sie Enter zweimal zum Beenden

**Nummerierte Liste:**
1. Klicken Sie auf das nummerierte Listen-Symbol (1., 2., 3.)
2. Funktioniert wie Aufzählungsliste
3. Nummern werden automatisch vergeben

### Bilder einfügen

1. **Upload**: Klicken Sie auf 🖼️
2. Wählen Sie eine Bilddatei (JPG, PNG, GIF, WEBP, SVG)
3. Maximale Dateigröße: 5MB

**Bildgröße anpassen:**
- **S** = 25% Breite (klein)
- **M** = 50% Breite (mittel, Standard)
- **L** = 75% Breite (groß)
- **XL** = 100% Breite (volle Breite)

**Bild-Position:**
- **◀️ Links**: Bild links, Text fließt rechts
- **▶️ Rechts**: Bild rechts, Text fließt links
- **⬛ Normal**: Bild ohne Text-Wrap (zentriert)

### Tabellen

1. Klicken Sie auf 📊 zum Einfügen
2. Standard: 3x3 Tabelle mit Header-Zeile
3. Größenänderbar durch Ziehen der Ränder
4. Header-Zeile hat blauen Hintergrund

**Tabellen bearbeiten:**
- Klicken Sie in eine Zelle zum Bearbeiten
- Nutzen Sie Tab für nächste Zelle
- Shift+Tab für vorherige Zelle

### Links einfügen

1. Markieren Sie den Text
2. Klicken Sie auf 🔗
3. Geben Sie die URL ein
4. Links öffnen automatisch in neuem Tab

### Layout-Features

#### 1. 2-Spalten-Layout ⬜⬜

**Verwendung:**
1. Klicken Sie auf den Button **⬜⬜** in der Toolbar
2. Ein 2-Spalten-Layout wird eingefügt
3. Klicken Sie in jede Spalte, um Inhalte hinzuzufügen
4. Jede Spalte unterstützt: Text, Bilder, Listen, Tabellen

**Anwendungsfälle:**
- Vergleiche (Vorher/Nachher)
- Pro/Contra-Listen
- Text neben Bild
- Feature-Übersichten

**Draggable:**
- Hover über das Layout → Griff-Symbol erscheint
- Klicken und ziehen zum Verschieben

#### 2. 3-Spalten-Layout ⬜⬜⬜

**Verwendung:**
1. Klicken Sie auf den Button **⬜⬜⬜** in der Toolbar
2. Ein 3-Spalten-Layout wird eingefügt
3. Ideal für Feature-Vergleiche oder Schritt-für-Schritt-Anleitungen

**Anwendungsfälle:**
- Feature-Vergleiche (Basis/Standard/Premium)
- Schritt-für-Schritt-Prozesse
- Team-Vorstellungen mit Bildern
- Drei-Punkte-Argumentation

**Mobile Ansicht:**
- Spalten werden automatisch untereinander angezeigt

#### 3. Hero-Slide 🎯

**Verwendung:**
1. Klicken Sie auf den Button **🎯** in der Toolbar
2. Eine Hero-Slide mit großem Titel und Untertitel wird eingefügt
3. Bearbeiten Sie Titel und Untertitel direkt

**Eigenschaften:**
- Großer, auffälliger Titel (3em)
- Untertitel mit reduzierter Opacity
- Gradient-Hintergrund (lila/violett)
- Zentrierte Ausrichtung
- Perfekt für Eröffnungs- und Abschluss-Slides

**Anwendungsfälle:**
- Webinar-Eröffnung
- Kapitel-Trenner
- Call-to-Action
- Abschluss-Slide

### Keyboard-Shortcuts

- **Strg/Cmd + B**: Fett
- **Strg/Cmd + I**: Kursiv
- **Strg/Cmd + U**: Unterstrichen
- **Strg/Cmd + Z**: Rückgängig
- **Strg/Cmd + Shift + Z**: Wiederholen

## Tipps & Best Practices

### Slide-Gestaltung

✅ **Kurz und prägnant**: Maximal 5-7 Bullet Points pro Slide
✅ **Visuelle Hierarchie**: Nutzen Sie Überschriften-Stufen konsistent
✅ **Bilder verwenden**: Ein Bild sagt mehr als 1000 Worte
✅ **Spalten für Struktur**: Organisieren Sie komplexe Inhalte in Spalten
✅ **Hero-Slides sparsam**: Nur für wichtige Meilensteine verwenden
✅ **Einheitliche Formatierung**: Verwenden Sie konsistente Farben und Stile

### Layout-Kombinationen

**Text + Bild (2-Spalten):**
```
┌────────────────┬────────────────┐
│ Text:          │ [Bild]         │
│ • Punkt 1      │                │
│ • Punkt 2      │                │
│ • Punkt 3      │                │
└────────────────┴────────────────┘
```

**Feature-Vergleich (3-Spalten):**
```
┌──────────┬──────────┬──────────┐
│ Feature A │ Feature B │ Feature C │
│ --------- │ --------- │ --------- │
│ Text...   │ Text...   │ Text...   │
└──────────┴──────────┴──────────┘
```

**Hero + Content-Slides:**
```
1. Hero-Slide (Eröffnung)
2. 3-Spalten (Übersicht)
3. 2-Spalten (Details)
4. Hero-Slide (Abschluss)
```

### Häufige Fehler vermeiden

❌ **Zu viel Text**: Slides sind Gedächtnisstützen, keine Essays
❌ **Zu kleine Bilder**: Verwenden Sie mindestens "M" (50%)
❌ **Zu viele Spalten**: Bei mobilen Geräten werden sie untereinander angezeigt
❌ **Inkonsistente Formatierung**: Nutzen Sie einheitliche Überschriften-Stufen
❌ **Überfüllte Slides**: Weniger ist mehr

### Sprechernotizen

Sprechernotizen werden für die automatische Sprachausgabe verwendet.

**Tipps für beste Qualität:**
- Schreiben Sie klare, vollständige deutsche Sätze
- Verwenden Sie Punkte, Kommas und Semikolons für natürliche Pausen
- Halten Sie Notizen übersichtlich (empfohlen: 2-4 Sätze pro Folie)
- Vermeiden Sie Abkürzungen und Akronyme ohne Erklärung

**Beispiel:**
```
Gute Sprechernotiz:
"Willkommen zu diesem Webinar. In den nächsten 30 Minuten 
werden wir drei wichtige Konzepte besprechen. Am Ende haben 
Sie die Möglichkeit, Ihr Wissen in einem Quiz zu testen."

Schlechte Sprechernotiz:
"Willkommen TTS 3 Konzepte Quiz"
```

## Workflow-Empfehlung

### Neue Slide erstellen

1. **Titel setzen**: Kurz und prägnant (maximal 5-7 Wörter)
2. **Layout wählen**: Standard, 2-Spalten, 3-Spalten, oder Hero
3. **Inhalt hinzufügen**: Text, Bilder, Listen
4. **Sprechernotiz**: Für automatische Sprachausgabe verfassen
5. **Speichern**: Webinar speichern

### PPTX/PDF importieren

1. **Upload**: PPTX/PDF hochladen unter "Import"
2. **Webinar erstellen**: Datei auswählen bei Webinar-Erstellung
3. **Automatisch**: Slides werden als TipTap JSON generiert
4. **Nachbearbeiten**: Layouts und Formatierung anpassen
5. **Sprechernotizen ergänzen**: Für automatische Sprachausgabe

### Webinar präsentieren

1. **Webinar öffnen**: "Anzeigen" im Admin-Panel
2. **Reveal.js**: Vollständige Präsentation mit Navigation
3. **Keyboard**: Pfeiltasten für Navigation
4. **Speaker-Notes**: Automatische Sprachausgabe
5. **Vollbild**: F-Taste für Vollbildmodus

## Troubleshooting

### Problem: Editor lädt nicht

**Lösung**: 
- Seite neu laden (F5)
- Browser-Cache leeren (Strg+Shift+R)
- In einem anderen Browser versuchen

### Problem: Bilder werden nicht angezeigt

**Lösung**: 
- Prüfen Sie die Dateigröße (max. 5MB)
- Unterstützte Formate: JPG, PNG, GIF, WEBP, SVG
- Stellen Sie sicher, dass das Bild erfolgreich hochgeladen wurde

### Problem: Layout wird nicht gespeichert

**Lösung**:
- Warten Sie, bis der Editor vollständig geladen ist
- Klicken Sie "Speichern" im Formular
- Überprüfen Sie, ob Sie angemeldet sind

### Problem: PPTX-Import funktioniert nicht

**Lösung**:
- Prüfen Sie das Dateiformat (.pptx, .ppt, .pdf)
- Max. Dateigröße: 50MB
- Komplexe Animationen werden nicht unterstützt
- Versuchen Sie, die Datei in PowerPoint/LibreOffice neu zu speichern

### Problem: Sprachausgabe funktioniert nicht

**Lösung**:
- Überprüfen Sie, ob Ihr Browser Audio erlaubt
- Stellen Sie sicher, dass die Lautstärke nicht auf 0 ist
- Verwenden Sie Chrome oder Edge für beste Ergebnisse
- Überprüfen Sie, ob Sprechernotizen vorhanden sind

### Problem: Quiz wird nicht angezeigt

**Lösung**:
- Stellen Sie sicher, dass Quiz-Fragen im Webinar angelegt sind
- Navigieren Sie zur letzten Folie
- Seite neu laden
